# PalindromeCheckerApp
Palindrome Checker App is a simple Java console application that checks whether a given string is a palindrome.
A palindrome is a word that reads the same forward and backward (example: madam, level).

🎯 Features

Displays welcome message

Shows application version

Initializes system successfully

(Next) Checks if a string is a palindrome

🛠 Technology Used

Java

Console Application
